# فولدر إضافي — الداش بورد وصفحة الدروس

## الملفات اللي فيه

```
new-pages/
├── dashboard.html          ← الصفحة الرئيسية (آية اليوم، تنبيهات، لوحة الشرف)
├── lessons.html            ← صفحة الدروس (ملخص + آية + صور/فيديو لكل درس)
├── images/
│   └── lessons/            ← صور كل درس تتحط هنا
└── videos/
    └── lessons/            ← فيديوهات كل درس تتحط هنا
```

## إزاي تركّبها مع مشروع الخريطة

1. فك ضغط الفولدر ده.
2. انسخ **محتوى** الفولدر (مش الفولدر نفسه) جوه نفس فولدر المشروع الأساسي (اللي فيه `index.html` بتاع الخريطة، وفولدرات `images` و `videos` بتاعتها).
3. لو فولدر `images` و `videos` أصلاً موجودين في المشروع الأساسي، هيندمجوا مع فولدر `lessons/` الجديد من غير ما يبوظوا حاجة — احتفظ بالاتنين.
4. من GitHub Desktop: هتلاقي الملفات الجديدة ظاهرة في قائمة التغييرات. اكتب وصف بسيط واعمل **Commit to main**، وبعدين **Push origin**.

بعد كده الروابط هتبقى:
- `.../dashboard.html` — الصفحة الرئيسية
- `.../lessons.html` — صفحة الدروس
- `.../index.html` — الخريطة التفاعلية (زي ما هي)

## أسماء ملفات صور وفيديوهات كل درس

صفحة الدروس بتدور على الصور والفيديوهات بالاسم اللي انت حاطه في كود `lessons.html` نفسه (جوه مصفوفة `lessons` في آخر الملف). دلوقتي مفيش أسماء محددة لكل درس — الدرس الأول بس ("رحلة شعب ج1") فيه صورة مقترحة باسم `01-rihla-1.jpg`.

### الطريقة الأسهل لإضافة صورة أو فيديو لأي درس:

1. افتح `lessons.html` بأي محرر نصوص (Notepad, VS Code, إلخ).
2. دور على الدرس اللي عايز تضيفله وسائط (كل درس عنوانه واضح جوه الكود، زي `title: "ساعتك كام"`).
3. هتلاقي جنبه سطرين:
   ```
   images: [],
   videos: []
   ```
4. اختار اسم ملف زيه ما تحب (مثلاً `05-saatak-kam.jpg`)، وحطه جوه الأقواس:
   ```
   images: ["05-saatak-kam.jpg"],
   videos: []
   ```
5. تقدر تحط أكتر من صورة لنفس الدرس:
   ```
   images: ["05-saatak-kam-1.jpg", "05-saatak-kam-2.jpg"],
   ```
6. احفظ الملف الاسم اللي كتبته في الكود بنفس الاسم بالظبط في فولدر `images/lessons/` (أو `videos/lessons/` للفيديو).

## تحديث محتوى الدرس (الآية والملخص)

في نفس الدرس جوه الكود، هتلاقي:
```
verseText: "",
verseRef: "",
summary: "",
```
احط بينهم آية الدرس ومرجعها وملخص الدرس (تقدر تسيب أسطر فاضية بين الفقرات بكتابة `\n\n` بين كل فقرة والتانية).
